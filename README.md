# Astra — AI 3D Avatar Studio

Astra is an AI-powered 3D model generator: describe what you want, or upload a
photo, and it builds a textured 3D model you can inspect, rig, and export.

**Live app:** https://ai-avatar-forge-3.preview.emergentagent.com/

## About this repository

This repo currently hosts a landing page (`index.html`) that introduces the
project and links out to the live app, since the app itself is built and
hosted on [Emergent](https://emergent.sh) rather than in this repository.

If you'd like the full application source (frontend + backend) mirrored here
instead of just this landing page, it can be pushed directly from Emergent's
own GitHub integration.
